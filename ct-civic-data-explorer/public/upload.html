Add a dataset

Upload a spreadsheet. Nothing is shown to anyone until you choose its fields and publish it on the next screen.

  1. Choose the file

    The first row must hold the column names. Rows may repeat, for example one row per town and industry.

    Formula cells use their saved values, so save the workbook in Excel first.

  2. Describe it

    Uploading again with the same name and reporting period creates a new version.

  3. What does each row describe?

    The first rows of your file. The highlighted column names each row; every other column becomes something you can show for it.
