Add a dataset

Upload a spreadsheet. Nothing is shown to anyone until you choose its fields and publish it on the next screen.

  1. Choose the file

    Use the first row for column names. A field may repeat across rows, for example when each program has several reporting periods.

    Formula cells use their saved values, so save the workbook in Excel first.

  2. Describe it

    Uploading again with the same name and reporting period creates a new version.

  3. Choose a primary field

    Choose an ID, a category, or a name to label the rows and start new reports. You can change this later in dataset settings.

Cancel

    Advanced: indicator definitions

    Not needed for most files. New columns are detected automatically. Use a definition only for a known indicator key that needs a particular unit or a computed ratio.
