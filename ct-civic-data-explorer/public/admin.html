Datasets

Upload a CSV or Excel workbook, then open a dataset to see its information, indicators and data.

The first row contains column names. Import one sheet at a time. Formula cells use their saved values; save the workbook in Excel before uploading.

Include a Town column. Towns may appear on multiple rows; text and numeric columns are detected automatically. Uploading the same name and period creates a new version.

Optional indicator definitions

New columns do not need registration. Use a definition for known indicator keys when you need a particular unit or a computed ratio.
